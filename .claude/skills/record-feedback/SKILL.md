# Record Feedback

1. Append a dated entry to `editorial/editorial-feedback.md` with his notes **verbatim** (quoted), and the chapter and version they refer to.
2. Classify each note as exactly one of:
   - **Universal**: a writing preference for everything he writes.
   - **Project**: specific to Glubina (tone, world, characters).
   - **Chapter**: applies to this chapter only.
   - **Example (do not reuse)**: sample dialogue, scenarios, or suggestions that illustrate a principle. Record the *principle* it demonstrates. Mark the example text itself as **never to be reused verbatim** unless he designated it as manuscript text.
3. For each universal or project lesson, write one line saying what it means in practice. Include when it *doesn't* apply, so it doesn't become a formula.
4. **Recurrence check.** If a lesson repeats an earlier entry, mark it `RECURRING`. Then update the instruction that should have prevented it: `narrative-principles.md`, `author-voice-profile.md`, or the relevant skill. Note that update in the entry.
5. If feedback contradicts the voice profile, the feedback wins. Revise the profile and note why.
6. If a note is a canon decision ("Timur doesn't call Zamir, he emails"), also record it in `editorial/canon-decisions.md`.
